Web Browsers

A web browser is software that allows users to access and view websites on the internet. It takes data from web servers and displays it in a readable format.

HTML (HyperText Markup Language)

HTML is the standard language used to create the structure of web pages. It defines elements such as headings, paragraphs, images, and links.

CSS (Cascading Style Sheets)

CSS is used to control the appearance of web pages. It allows developers to change colors, fonts, spacing, and layout.

JavaScript

JavaScript is a programming language that adds interactivity to web pages. It allows users to interact with elements like buttons, forms, and dynamic content.

DNS (Domain Name System)

DNS is a system that translates domain names, like google.com, into IP addresses so that browsers can locate web servers.

HTTP (Hypertext Transfer Protocol)

HTTP is the protocol used to transfer data between a web browser and a server. It defines how requests and responses are sent over the internet.

Rendering Engines

A rendering engine is a component of a browser that processes HTML, CSS, and JavaScript to display the final web page on the screen.
