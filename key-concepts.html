Web Browsers

A web browser is software that allows users to access and view websites on the internet.

HTML

HTML structures a webpage using elements like headings, text, images, and links.

CSS

CSS controls the look of a webpage, including colors, layout, and spacing.

JavaScript

JavaScript adds interactivity, allowing users to interact with buttons, forms, and dynamic content.

DNS

DNS translates website names into IP addresses so browsers can locate servers.

HTTP

HTTP is the protocol used for transferring data between a browser and a server.

HTTPS

HTTPS is a secure version of HTTP that encrypts data to protect user information.

Rendering Engine

A rendering engine processes HTML, CSS, and JavaScript to display a webpage on the screen.
