Introduction

A web browser is software that turns data into an easy to read format for people using the World Wide Web. People use web browsers everday for tasks like shopping online, watching videos, checking emails, and viewing their social media.

Modern browsers are fast, visually appealing, and capable of running complex web applications. However, early browsers were simple and limited compared to what people use today.
